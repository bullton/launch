SUBSCRIBE · 订阅发射日历

把下面这个链接添加到 Google Calendar / Apple Calendar / Outlook， 所有未来发射计划会自动同步到你的日历里，无需反复复制粘贴。

FORMAT: iCalendar (RFC 5545) UPDATES: every 6-12 h (Google Calendar poll) EVENTS: —

Google Calendar

  1. 打开 Google Calendar
  2. 右上 ⚙ → Settings → 左栏 Add calendar → From URL
  3. 粘贴上面的 URL → Add calendar

Apple Calendar (iOS / macOS)

  1. macOS: 系统设置 → Internet Accounts → Add Account → Other → Add CalDAV Account
  2. iOS: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar
  3. Account Type 选 Manual，粘贴 URL

Outlook

  1. Add calendar → Subscribe from web
  2. 粘贴 URL
